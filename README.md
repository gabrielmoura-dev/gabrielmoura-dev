## 🧑‍💻 Sobre Mim

Sou estudante de **Análise e Desenvolvimento de Sistemas na FIAP** e estou construindo minha carreira como desenvolvedor Full-Stack. Antes de migrar para tecnologia, trabalhei com **bancos de dados Oracle no Tribunal de Justiça do Rio Grande do Sul**, onde aprendi a operar em ambientes de alta responsabilidade onde precisão é inegociável.

Hoje construo aplicações web do front ao back, combinando uma base técnica em crescimento com olhar para **UI/UX** e uma mentalidade de resolução de problemas moldada por experiência institucional real. Busco meu primeiro **estágio em desenvolvimento** onde possa contribuir com um time que valoriza código limpo, colaboração e aprendizado contínuo.
